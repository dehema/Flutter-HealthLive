# HealthLive 美术资源列表

> 本文档列出客户端需要的美术资源、用途与放置路径。资源由你准备后放入对应目录，代码中通过 `assets/` 或网络 URL 引用。

---

## 1. 资源目录约定

```
assets/
├── images/          # 位图：封面、Banner、占位图、空状态插画
├── icons/           # 应用内图标、分类图标（PNG/SVG 导出 PNG）
└── data/            # 可选：本地静态 JSON（仅开发/兜底，正式环境走 Go API）
```

`pubspec.yaml` 已声明以上目录，新增子目录时需同步更新 `flutter.assets` 配置。

## 8. 内容配图（后端 CDN）

以下内容图**不建议打进安装包**，由运营/后端上传至对象存储，数据库（PostgreSQL）存 URL，API 返回 `cover_url`：

| 类型 | 建议比例 | 建议宽度 | 格式 | 说明 |
|------|----------|----------|------|------|
| 列表封面 | 1:1 或 4:3 | 480px 起 | WebP/JPEG | 卡片左侧缩略图 |
| 详情头图 | 16:9 | 1080px | WebP/JPEG | 详情页顶部大图 |
| 每日一知 | 16:9 或 2:1 | 1080px | WebP/JPEG | 首页 Banner 背景（可选） |

**命名建议（CDN）：** `contents/{category}/{content_id}/cover.webp`

## 9. 交付检查清单

准备资源时请确认：

- [ ] 文件名与上表一致（小写、下划线）
- [ ] 图标提供 @3x 或矢量导出 PNG，边缘留白一致
- [ ] 位图尽量 WebP/PNG，单张列表图 < 80KB
- [ ] 品牌色与 App 主题接近（主色 `#3D8B7A`、背景 `#F7F9F8`）
- [ ] 放入目录后执行 `flutter pub get` 无需改代码即可被 Asset Bundle 识别（新子目录需改 `pubspec.yaml`）
