# 打包指令

```powershell
cd F:\Project\Flutter\Flutter-HealthLive
flutter build apk -v
```

APK 输出路径：`build\app\outputs\flutter-apk\HealthLive.apk`

> Flutter 控制台可能仍显示 `app-release.apk`，它是同一文件的硬链接，实际分发请使用 `HealthLive.apk`。

# 国内网络：Maven 镜像（必配）

Flutter 插件（如 `flutter_secure_storage`）的 `buildscript` 会直连 Google Maven，需在 `android/build.gradle.kts` 为 **subprojects** 注入阿里云镜像（项目已配置）。

`android/build.gradle.kts` 中应包含：

```kotlin
subprojects {
    buildscript {
        repositories {
            maven { url = uri("https://maven.aliyun.com/repository/google") }
            maven { url = uri("https://maven.aliyun.com/repository/central") }
            maven { url = uri("https://maven.aliyun.com/repository/public") }
            maven { url = uri("https://maven.aliyun.com/repository/gradle-plugin") }
            google()
            mavenCentral()
        }
    }
    repositories {
        maven { url = uri("https://maven.aliyun.com/repository/google") }
        maven { url = uri("https://maven.aliyun.com/repository/central") }
        maven { url = uri("https://maven.aliyun.com/repository/public") }
        google()
        mavenCentral()
    }
}
```

验证镜像可用：
[https://maven.aliyun.com/repository/google/com/android/tools/build/gradle/8.5.1/gradle-8.5.1.pom](https://maven.aliyun.com/repository/google/com/android/tools/build/gradle/8.5.1/gradle-8.5.1.pom)

> 勿使用全局 `init.gradle` 的 `allprojects` / `beforeProject` 无差别注入，会与 Flutter 内置 `:gradle` 工程冲突。

# 修改 Flutter SDK 配置（可选，与 init.gradle 配合）

dependencyResolutionManagement {

# Windows 开发者模式

带 plugin 的项目执行 `flutter pub get` 需要 symlink 支持：设置 → 隐私和安全性 → 开发者选项 → 开启**开发人员模式**。

# 常见问题


| 报错                                            | 处理                                                                        |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| `dl.google.com Connection timed out`          | 确认 `android/build.gradle.kts` 的 subprojects 镜像已配置，执行 `gradlew --stop` 后重试 |
| `NDK not configured` / 缺少 `source.properties` | SDK Manager 重装 NDK 28.2.13676358                                          |
| `platforms;android-34` 找不到                    | SDK Manager 安装 API 34，或项目已用 `afterEvaluate` 统一 compileSdk=36              |
| `CMake '3.22.1' was not found`                | SDK Tools 安装 CMake 3.22.1                                                 |
| `buildLogic.lock` 锁冲突                         | 关闭 Android Studio Sync，只保留一个构建进程                                          |
| Gradle 9.1.0 下载慢                              | 已缓存在 `%USERPROFILE%\.gradle\wrapper\dists\`，无需额外配置                        |
| `symlink support` / 开发者模式                     | Windows 设置 → 开发者选项 → 开启开发人员模式                                             |


# 构建工具说明（JDK / SDK / NDK / CMake 等）

打 Android APK 时，Flutter 会依次用到下面这些东西。可以把它理解成一条流水线：**Dart 代码 → Gradle 编排 → JDK 运行构建 → Android SDK 提供 API → NDK/CMake 编译原生代码 → 产出 APK**。

```
flutter build apk
    │
    ├─ Flutter SDK      编译 Dart、打包资源
    ├─ Gradle           驱动整个 Android 构建（Wrapper 自动下载 Gradle 9.1.0）
    ├─ JDK              运行 Gradle 和 Java/Kotlin 编译器
    ├─ Android SDK      提供 Android API、Build-Tools、aapt 等
    ├─ NDK + CMake      编译 C/C++ 原生代码（引擎、部分 plugin）
    └─ Maven 依赖       AGP、Kotlin、第三方 Android 库
```

## Flutter SDK


| 项目        | 说明                                                                         |
| --------- | -------------------------------------------------------------------------- |
| **作用**    | 编译 Dart 代码、管理依赖、调用各平台构建工具                                                  |
| **本项目路径** | `F:\ProgramFiles\flutter`（**路径不能有空格**）                                     |
| **常见问题**  | 路径含空格导致构建脚本失败；`flutter pub get` 在 Windows 上需要**开发人员模式**（plugin 需要 symlink） |


## Gradle（构建编排器）


| 项目       | 说明                                                                              |
| -------- | ------------------------------------------------------------------------------- |
| **作用**   | Android 构建的「总调度」：拉依赖、编译 Java/Kotlin、调用 NDK/CMake、打 APK                          |
| **版本**   | 本项目使用 **Gradle 9.1.0**（由 `android/gradle/wrapper/gradle-wrapper.properties` 指定） |
| **存放位置** | `%USERPROFILE%\.gradle\wrapper\dists\gradle-9.1.0-all\`（下载一次后本地复用）              |
| **常见问题** | 首次下载超时 → 用腾讯云镜像或手动放 zip；`buildLogic.lock` → 多进程抢锁，先 `gradlew --stop`            |


## JDK（Java 开发工具包）


| 项目        | 说明                                                                       |
| --------- | ------------------------------------------------------------------------ |
| **作用**    | 运行 Gradle 本身，以及编译项目里的 Java/Kotlin 代码                                     |
| **来源**    | 通常用 **Android Studio 自带的 JBR**（JetBrains Runtime），Gradle 会自动选用           |
| **本项目要求** | Java **17**（见 `android/app/build.gradle.kts` 的 `JavaVersion.VERSION_17`） |
| **常见问题**  | 版本过低导致 AGP 报错；一般装 Android Studio 即可，无需单独配                                |


## Android SDK

Android SDK 是一组工具的集合，不是一个单独程序。下面几项都在 SDK Manager 里安装。

### Android SDK Platform（API Level）


| 项目        | 说明                                                                                                             |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| **作用**    | 提供对应 Android 版本的系统 API（`android.`* 类库），编译时引用                                                                   |
| **本项目需要** | **API 36**（主工程 compileSdk）；部分插件还需要 **API 34**                                                                  |
| **存放位置**  | `E:\Programs\Android\Sdk\platforms\android-36\` 等                                                              |
| **常见问题**  | `Failed to find Platform SDK with path: platforms;android-34` → 缺对应 API，需安装或在 `build.gradle.kts` 统一 compileSdk |


### Android SDK Build-Tools


| 项目        | 说明                                                 |
| --------- | -------------------------------------------------- |
| **作用**    | 打包 APK 用的工具：`aapt2`（资源编译）、`zipalign`、`apksigner` 等 |
| **本项目需要** | **36.0.0** 或更高                                     |
| **存放位置**  | `E:\Programs\Android\Sdk\build-tools\36.0.0\`      |
| **常见问题**  | 版本与 compileSdk 不匹配时可能警告，一般装与 Platform 同主版本即可       |


### Android SDK Platform-Tools


| 项目         | 说明                                        |
| ---------- | ----------------------------------------- |
| **作用**     | `adb`（调试安装 APK）、`fastboot` 等，开发调试时用       |
| **打包是否必须** | 打 APK **不强制**，但 Android Studio 通常会一起装     |
| **存放位置**   | `E:\Programs\Android\Sdk\platform-tools\` |


### Android SDK Command-line Tools


| 项目       | 说明                                                        |
| -------- | --------------------------------------------------------- |
| **作用**   | 提供 `sdkmanager` 命令行，无 GUI 安装 SDK 组件                       |
| **存放位置** | `E:\Programs\Android\Sdk\cmdline-tools\latest\`           |
| **常见问题** | 国内网络下 `sdkmanager` 拉清单失败 → 优先用 Android Studio SDK Manager |


## NDK（Native Development Kit）


| 项目        | 说明                                                                                            |
| --------- | --------------------------------------------------------------------------------------------- |
| **作用**    | 编译 **C/C++ 原生代码**：Flutter 引擎、以及带 native 实现的 plugin（如 `hive_flutter`、`flutter_secure_storage`） |
| **本项目版本** | **28.2.13676358**（Flutter 在 `gradle_utils.dart` 里指定）                                          |
| **安装方式**  | SDK Tools → **NDK (Side by side)** → 勾选 28.2.13676358                                         |
| **存放位置**  | `E:\Programs\Android\Sdk\ndk\28.2.13676358\`                                                  |
| **常见问题**  | `NDK not configured` → 未安装；`did not have a source.properties file` → 下载不完整，删掉目录重装             |


## CMake


| 项目        | 说明                                                    |
| --------- | ----------------------------------------------------- |
| **作用**    | 生成原生 C/C++ 的编译脚本，配合 NDK 使用（Flutter 引擎 CMake 构建）       |
| **本项目版本** | **3.22.1**                                            |
| **安装方式**  | SDK Tools → **CMake** → 勾选 3.22.1                     |
| **存放位置**  | `E:\Programs\Android\Sdk\cmake\3.22.1\`               |
| **常见问题**  | `CMake '3.22.1' was not found` → SDK Tools 里未安装 CMake |


## AGP（Android Gradle Plugin）


| 项目       | 说明                                                                                   |
| -------- | ------------------------------------------------------------------------------------ |
| **作用**   | Gradle 的 Android 插件，把「Java/Kotlin + 资源 + NDK」组装成 APK                                 |
| **版本**   | 主工程 **9.0.1**；部分 Flutter 插件内部依赖 **8.5.1** 等                                          |
| **下载来源** | Google Maven（`dl.google.com`），国内需配阿里云镜像                                              |
| **常见问题** | `Could not resolve com.android.tools.build:gradle:8.5.1` → 网络超时，见上文 subprojects 镜像配置 |


## Maven 仓库 / 镜像


| 项目        | 说明                                                                             |
| --------- | ------------------------------------------------------------------------------ |
| **作用**    | 下载 AGP、Kotlin 插件、AndroidX、第三方 jar/aar                                          |
| **本项目配置** | `android/settings.gradle.kts` + `android/build.gradle.kts` 的 subprojects 阿里云镜像 |
| **常见问题**  | 插件子工程仍走 `dl.google.com` → 必须在 **subprojects.buildscript** 里也加镜像                |
